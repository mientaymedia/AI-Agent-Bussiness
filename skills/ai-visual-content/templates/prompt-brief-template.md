# AI Visual Content — Prompt Brief Template

Fill this out before generating anything. Forces the S-C-O-P-E framework before touching a tool, so output stays consistent across sessions and tools.

```markdown
## Visual Content Brief: [Project/Campaign Name]

**Asset Type:** [Static image / Video / Both]
**Purpose:** [Sales page hero / Social ad / Thumbnail / Lifestyle content]
**Platform & Aspect Ratio:** [e.g. TikTok 9:16, Facebook 1:1, Sales page 16:9]

### S-C-O-P-E
- **Subject:** [Exact product/person + distinguishing details]
- **Context:** [Setting/background that signals target buyer's world]
- **Optics:** [Camera angle, lighting, lens feel]
- **Purpose:** [What this image/video needs to accomplish — stop-scroll, trust-build, demonstrate use]
- **Exclusions:** [No text in-image, no competitor logos, no exaggerated claims, etc.]

### Brand Consistency Check
- Color palette: [hex codes if applicable]
- Reference photo attached: [Y/N — for image-to-image consistency]
- Persona consistency needed across set: [Y/N]

### Tool Selected
[Tool name] — Reason: [why this tool for this asset]

### Variations Requested
[Number] — Varying: [what changes between variations, what stays fixed]

### Quality Checklist (before publishing)
- [ ] No distorted hands/fingers/faces
- [ ] No garbled in-image text
- [ ] Lighting consistent across frame
- [ ] Passes "AI smell" check against 2-3 real reference photos
- [ ] Selected best of 3-5 generations, not the first output
```
